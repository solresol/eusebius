\begin{frame}{Project Overview}
  \begin{itemize}
    \item The corpus is Eusebius of Caesarea's \emph{Historia Ecclesiastica}.
    \item The source text is OpenGreekAndLatin First1KGreek TEI.
    \item PostgreSQL on \texttt{raksasa} is the canonical store.
    \item The public site is static HTML deployed to \texttt{merah}.
  \end{itemize}
\end{frame}

\begin{frame}{Data Ingestion}
  \begin{itemize}
    \item \texttt{scripts/import\_first1k.py} fetches Greek and English TEI.
    \item The importer stores source metadata, passages, word counts, and canonical references.
    \item Title pages and book markers are not treated as passage text.
    \item The First1K English is kept as a rough reference, not a clean public translation.
  \end{itemize}
\end{frame}

\begin{frame}{Static Site}
  \begin{itemize}
    \item \texttt{scripts/generate\_site.py} reads from PostgreSQL.
    \item The site reports corpus scale, book-level counts, top Greek terms, and sample passages.
    \item Clean AI translations are shown when available.
    \item Rough First1K English appears only as a labelled reference source.
  \end{itemize}
\end{frame}

\begin{frame}{Translation Pipeline}
  \begin{itemize}
    \item \texttt{scripts/translate\_passages.py} supports cleanup and translation modes.
    \item Runs are stored in \texttt{ai\_translation\_runs} with model, prompt version, token counts, status, and errors.
    \item Cleanup mode uses \texttt{gpt-5.4-mini} with Greek plus rough English and a high daily token budget.
    \item Translation mode uses \texttt{gpt-5.5} from Greek with a 10,000-token daily budget.
  \end{itemize}
\end{frame}

\begin{frame}{Research Direction}
  \begin{itemize}
    \item Start with explainable features: counts, co-occurrence, source labels, and transparent networks.
    \item Use LLM calls only for bounded translation, planning, and later documentary-comic work.
    \item Keep generated images and other bulky artifacts out of Git.
  \end{itemize}
\end{frame}
